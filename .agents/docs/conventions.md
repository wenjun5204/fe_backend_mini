# 编码与文案规范

## 一、合规文案词表（强执行）

### 禁用词（用户可见文案中出现即 Bug）

运势、吉凶、求签、算命、占卜、八字、塔罗、改运、挡灾、化解、开光、大师、命中注定、犯太岁、本命、凶、忌、破财、招财进宝（涉财诱导）、降血压、降血糖、治疗、理疗、排毒、药用、偏方、卦象、卦运、宜忌、生门、吉位、凶位、能成、不行、会有、注定、天意、预示、有灾

> 词表源自 v1 福签时代但**继续对全部用户可见文案生效**（合规红线不随产品转型失效）；「不行/能成/会有/注定/天意/预示」禁的是**结果断言句式**——描述行为建议，不断言结果。

### 统一替代表

| 禁用概念 | 统一用词 |
|---|---|
| 抽签/算卦 | 抽福签 / 接福 |
| 运势 | 福气 |
| 吉凶 | 平安 / 顺遂 |
| 开光 | 祝福 |
| 今日宜忌 | 今日宜（永不输出「忌」） |

### 新增文案的检查流程

任何新增用户可见文案（含接口返回的 message、通知模板、分享卡片文案）合入前必须过一遍禁用词表；机械检查脚本化（可用 grep 扫描禁用词清单）。

## 二、交互与 UI 硬规范（面向大众用户,保留大字号可读性）

1. 正文字号 ≥ 17pt（约 34rpx），核心信息 ≥ 22pt
2. 主按钮高度 ≥ 88rpx，一屏 ≤ 1 个主按钮，主按钮必须红色系
3. 任何功能 ≤ 3 次点击到达；流程设计目标零键盘输入（团名/家族名默认生成）
4. 文案口语化、用「您」、禁英文术语：「授权」→「允许」，「提交」→「完成」
5. 动画 ≤ 2.5 秒，提供跳过；所有操作有明确的成功反馈（toast/震动/动画）
6. 主操作（渐变胶囊按钮）视觉权重最高，次操作用暖白底细线弱化

## 三、视觉规范（v2 暖白体系，实际生效于 `miniprogram-nianjiashi/app.wxss` 视觉令牌）

| 项 | 值 |
|---|---|
| 页面底色 | 暖白 `#fbfaf7` |
| 主文字 | 墨字 `#1c1c28`，次级 `#55555f`，弱化 `#9a9aa4` |
| 主色 | 霞橘渐变 `#ff7a59 → #ff4d6d`（主按钮/强调） |
| 辅色 | 雾紫 `#6c5ce7`、青金 `#12b2a3`（头像底色轮换/次要强调） |
| 分割线 | `#eceae4` |
| 语义色 | 成功绿 `#2e7d4f`，警示橙 `#e8943a`，危险红 `#c0564a`（避免红绿并置做状态对比） |
| 班次色 | 早=玫红 `#ff4d6d`、中=橙 `#e8943a`、夜=藏蓝 `#3d4a5c`、休=灰 `#c8cdd3` |

**风格指引（清新、大气、克制——做减法不做加法）**：

1. 细线代替重框：边框 ≤2rpx 细线；选中态 = 细彩线 + 浅色底（4rpx 下划线 / 5-7% 主色底），禁大面积高饱和填充
2. 分隔线列表代替卡片堆叠：同构多选项用列表行 + 2rpx 分隔线，不逐个描边成卡
3. 一页一个视觉焦点：渐变主按钮或深色 hero 卡二选一，其余元素全部让路
4. 间距宁松勿紧：区块间距 ≥24rpx，列表行内边距 ≥26rpx；弹层内容层级 ≤6 层，超了先砍信息再谈排版
5. 文字层级三档足够：核心数字（衬线大字重）> 标题（700）> 说明（弱化灰）；禁四种以上字号混排
6. emoji 仅用于功能性图标位（图例/入口），每屏 ≤3 处

## 四、后端规范

- 分层：controller（DTO + 参数校验）→ service（业务）→ repository（数据）
- 接口出入参一律 DTO，字段命名 camelCase，与 OpenAPI 契约一致；改接口先改契约
- 错误返回统一结构 `{code, message, data}`；message 面向用户，须过合规词表
- 兑底异常处理器（50000）必须打全量堆栈日志，禁止吞异常（前端只见错误码，真相在日志）
- 频控类逻辑（催福 3 次/人/天、通知 4 条/人/天）在 service 层实现，写单测
- 福值变更必须走「福值事件」路径，禁止直接 update 余额字段（保证可审计、只增不减）
- **事务注解铁律**：`@Transactional(readOnly=true)` 方法内禁止任何写库（含 orElseGet 兜底 save）——H2 不报错但 MySQL 生产必炸；需要兜底写的方法不加 readOnly

## 五、小程序规范

- 原生框架，不引入 UI 库（保持包体小、低端机流畅）
- 家人模块传参用家族邀请码（inviteCode）；各页面 onLoad 里处理分享进入场景
- 网络层统一封装 `utils/request.js`，双通道开关 USE_CLOUD（true=云托管 callContainer/false=本地 wx.request），环境 ID/服务名在文件顶部常量；错误 toast 文案过合规词表
- 分享卡片标题随分享物走（值班表/生日福卡/时光胶囊各有模板，见各页面 share 配置）；分享 title 属用户可见文案，同样须过合规词表

- 提交信息：`feat/fix/docs/refactor: 中文描述`
