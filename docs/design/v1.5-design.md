## 1. 后端设计(backend/)

### 1.1 数据库变更(H2,全为增量)

```
ALTER TABLE fortune_draw_record ADD COLUMN task_item VARCHAR(24) NULL;  -- 完成的今日宜事项文本(历史行 NULL,兼容)
```

### 1.2 卦位(gua)生成规则

- `GuaService.guaOfDate(familyId, date)`:确定性映射(无状态),`values[(familyId*31 + epochDay) % 8]`——同家族同日恒定,跨日轮换;**不参与等级概率**。
- `cardTheme` 映射内置常量表:QIAN=云鹤/DUI=锦鲤/LI=灯笼/ZHEN=春雷/XUN=风铃/KAN=锦鲤戏水/GEN=山景/KUN=花开。
- `DailyFortuneCardEntity` 增加 `gua`/`cardTheme` 冗余列(生成当日卡时写入,读取免计算)。

### 1.3 八卦阵 BaguaService(纯推导,无写入)

`GET /api/bagua/status` 单次聚合查询(家族维度),进度口径:

| 卦 | current 来源 | target |
|---|---|---|
| 乾 | 连续天数 d:从今日回溯,每日「全员已抽」(fortune_draw_record 按日计数=成员数);中断即止 | 7 |
| 兑 | BlessEvent(type=SHARE_CARD, familyId) 计数 | 30 |
| 离 | fortune_draw_record.task_item LIKE '%早睡%' 的去重(用户,日期)数 | 30 |
| 震 | family memberCount ≥ 2 → current=memberCount-1 | 1 |
| 巽 | task_item LIKE '%打电话%' 计数 | 10 |
| 坎 | task_item LIKE '%喝水%' 的去重(用户,日期)数 | 30 |
| 艮 | max(成员个人连续抽卡天数) | 30 |
| 坤 | 节气当日(内置 2026-2030 节气日期离线表)task_item 任意完成计数 | 1 |

- `lit = current >= target`;响应只读,不落进度表(每次现算,数据量 MVP 级无压力)。
- 8 卦全亮且 `family_milestone` 无 `BAGUA_COMPLETE` → 响应 `complete=true, celebrated=false`,前端庆祝后调 `POST /api/bagua/celebrate`?——**否**,按契约只读;庆祝标记在**下次 status 查询时由服务端自动落 milestone 并返回 celebrated=true**?——不符合「读接口无副作用」。
- **决策(决策记录 #15)**:增加轻量写接口 `POST /api/bagua/celebrate`(幂等,落 family_milestone),前端庆祝动效结束后调用。→ 该接口需补进契约(见 §4 契约补遗)。
- `completeFortuneTask` 接受可选 `taskItem`,校验属于当日 yiItems 后写入 `task_item` 列;缺省保持旧行为(不写)。

### 1.4 解忧册 JieyouService

- `JieyouQuoteLib`:120 条内置常量(促成/缓行/放下 ×40,每条 ≤16 字,启动时全量过合规词表断言,含 v1.5 追加词)。
- `GET /api/jieyou/quote`:查 `jieyou_daily_record`,无则纯随机选一条落库;有则返回同条(幂等)。`pageNo = quoteId`。不接收、不存储任何问题内容。

### 1.5 订阅 NotifyService

- `POST /api/notify/subscribe`:登记 grant(accepted=false 也登记);`remainingQuotaToday = grants(accepted) - sends(today)`,下限 0。
- `GET /api/notify/status`:`subscribed = grants(accepted) - sends(today) > 0`,`dailyLimit = 4`。
- 发送动作(真实微信 API 调用)不在 v1.5 范围——仅额度账本;模板 ID 配置于 application.yml(`notify.templates.*`),开发期占位。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 历史行 task_item 为 NULL,离/坎/巽进度偏小 | 文案口径「从今往后一起点亮」,不做数据回填 |
| H2 ALTER TABLE 兼容 | schema.sql 为建库全量脚本(开发库可重建),data.sql 保留种子 |
| 罗盘动画低端机掉帧 | rAF + transform/opacity 合成层动画,禁 box-shadow 逐帧变化 |
| 订阅模板未申请 | application.yml 占位模板 ID,联调开关 `notify.enabled=false` |
