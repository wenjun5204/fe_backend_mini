产品叙事 · 四凑链路

凑时间（投票·MVP）→ 凑人头（收集填表·v1.1 预览页已做进原型）→ 凑分工（群待办·v1.2）→ 沉淀（群日历·v1.3，个人主体可做）。每个环节的产出是下一环节的输入：投票定档名单 = 后续协作的人员底册。
AA 记账已彻底砍除（D5）：收钱交给微信官方「群收款」，本产品不碰资金。
心理引擎：组织者面子（定档卡署名+盖章）· 搭把手（全点选+「我来」）· 围观（数字会动的卡片）；催办话术全走召唤语气，不走质问（「这场还缺个人搭把手」而非「还差你的那份」）。
AI 高情商回复已移出（决策 D4：官方类目政策，个人主体不可上线 AI 生成服务），迁企业主体后回归。

设计方向 · 群主的白板

组织一群人的工具就该长得像组织者的家伙什儿：记号笔写主操作，荧光笔点亮"我有空"的时段，票数用正字计数（一人一画、五个一正），最后盖章定档——白板上的事，落章才算数。

试试看（四凑链路全流程）

  • 进「投票」页，点亮你有空的时段，点「就这些时间我有空」
  • 切到「组织者视角」，看每个时段的名单，对周六下午点「定这个」——盖章动画
  • 定档后到场名单自动沉淀——点「给到场的人分个工」看人员底册流向
  • 点首页链路上的「凑人头」，看 v1.1 收集填表预览——填表 → 汇总 → 导出
  • 点「凑分工」看 v1.2 群待办：群友点「我来」认领、点「搞定了」打钩；认领的事可「转给别人」放回池子（可改不可逃）；发起人视角可「催一下」空缺事项
  • 投票页底部「我也发起一个」= 发起人候补的转化入口；待办/收集的催办话术走召唤语气（PRD §1.2 红线）
  • 点「沉淀」看群日历 v1.3：月日历 + 链路小点 + 凝聚力分 + 战功卡
