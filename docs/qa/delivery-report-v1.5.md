## 4. 遗留事项(不阻断,按优先级)

1. **订阅模板 ID**:小程序 `card.js` 的 `NOTIFY_TEMPLATE_ID` 与后端 `application.properties` 均为占位,微信后台申请后替换;占位期按 accepted=false 静默登记,功能不受影响。
2. **真实订阅发送**:v1.5 仅额度账本,发送动作待模板审批后接线。
3. **真机体验项**:罗盘振动(模拟器不支持振动,真机预览可验)、订阅弹窗与分享面板排队顺序。
4. **音效**:如需真实点击音,提供 3 个短音频文件后接 `wx.createInnerAudioContext`。
5. **PR**:分支已推送,PR 未创建(目标分支待确认,建议 feature/quanjiafu-mvp)。
6. **设置页占位**:家庭关系(退出/转让/解散)与隐身榜外为占位/本地开关,待服务端能力上线接线。
