# 测试用例 v2.0 —— 念家时·日子管家（Stage 8 产出）

> 从 `docs/requirements/requirements-v2.0-days.md` 验收标准 + `api/openapi.yaml` v1.6.0 tag=days 契约派生。
> 定位：**端到端人工测试**（真机小程序操作），与 `DaysApiIntegrationTest` 22 条接口集成用例互补——集成层已覆盖的错误码/排序/幂等在此仅作界面路径复验，重点补集成测试覆盖不到的：界面交互、跨端状态一致性、多用户多设备、网络异常、跨天时间边界。
> 环境要求：微信开发者工具 + 真机各一台；至少 3 个测试账号（A=户主、B=同家族成员、C=未加入家族）；后端可连云托管与本地两通道。
> 优先级：P0=主路径/合规红线，提测必须全过；P1=重要分支；P2=低频/防御性。
> 日期基准：执行时以「当天」为 T0，相对天数按执行日推算；示例日期以 2026-10-10 为 T0 举例。

## 执行说明

- E 模块用 curl/Apifox 带 X-WX-OPENID 头直接调 /api/days/reminder-due；其余模块全部真机小程序操作（开发者工具执行需备注「工具模拟，真机复核」）。
- F 模块需两台设备/两个开发者工具实例同时登录不同账号；家族关系用既有邀请码链路准备。
- A6/D1 涉及跨天，可安排「隔夜批」或用可调时间的本地后端环境执行。
- 与 `DaysApiIntegrationTest` 22 条的关系：错误码、排序、幂等、频控截断在接口层已绿，本文 G3/E4 等侧重**界面呈现与人工可感知行为**，两者都过才算该功能提测通过。
