## 1. 产品概述

### 1.1 一句话定位

> **每天为全家抽一张福卡，做点小事攒福气，全家人一起把福值抬上家族榜。**

### 1.2 设计哲学：心理引擎驱动，功能只是载体

前序方案（健康打卡互助团）的根本问题：**健康是中老年的焦虑，不是快乐**。焦虑产品留得住人但传不开；转发传播需要的是快乐、惦记和面子。

本方案把产品骨架（家庭组队、每日微任务、催一下、排行榜）全部保留，但心理引擎全换：

| 引擎 | 心理机制 | 本方案对应设计 |
|---|---|---|
| 祈福求安（主引擎） | 家人平安 > 一切，为家人做事心甘情愿 | 每日福卡：抽的不是自己的签，是**全家的平安** |
| 同辈攀比（裂变引擎） | 家族与家族之间的面子战 | 家族福值榜 + 「满门福气」门牌 |
| 被子女需要 | 怕成为负担，渴望价值感 | 子女给父母「添福」，父母给孙辈「送平安」 |
| 怕死但不锻炼（暗线） | 健康焦虑强、行动力弱 | 微任务藏在福卡里，完成任务的回报是"明天福卡更旺" |

**核心区别**：健康打卡问用户"你今天做没做"（质问感）；福卡对用户说"你为家人积福了"（授予感）。

### 1.3 要解决的问题

| 用户侧痛点 | 方案 |
|---|---|
| 想为家人祈福但没有仪式载体 | 每日福卡：摇一摇、金光、翻卡，动作有肌肉记忆 |
| 转发早安图没新意，显得老土 | 福卡是精美动态卡片，转出去"有面子" |
| 健康任务坚持不了 | 任务降级为"福卡附赠"：不做不扣福，做了多攒福 |
| 家族群没有共同活动 | 家族福值池：全家人的行为汇成一件事 |

### 1.4 北极星指标

**每日「福卡激活」家庭数（Daily Blessed Families, DBF）**

定义：当日至少 2 名家庭成员完成抽卡并转发的家庭数。它同时衡量留存（家人回访）与传播（转发动作）。

## 2. 目标用户（沿用前序画像，行为假设更新）

- **王阿姨（58，核心用户）**：从前一天发 3 张早安图；现在发 1 张福卡——更精美、带全家名字、还能看福值。转发理由从"维护关系"升级为"为家人求平安"。
- **小刘（31，付费+拉新用户）**：以前打电话尬聊；现在每天给妈妈的福卡「添福」一次（免费动作，情感价值极高），节日买「全家福修复」孝心付费。
- **老陈（63，攀比传播用户）**：看到老王家门牌"满门福气"不服 → 拉自己全家进榜 → 他的子女也被拉进来。

## 3. 核心机制设计

### 3.1 福值体系（统一货币）

| 行为 | 福值 | 说明 |
|---|---|---|
| 每日抽福卡 | +5 | 上限 1 次/天 |
| 福卡转发到家人群（激活） | +10 | 核心行为，转发即激活 |
| 完成福卡附赠微任务 | +15 | 如"多喝两杯水"、"散步 20 分钟" |
| 家人给你「添福」 | +8/次 | 每人每天可给每位家人添福 1 次 |
| 连续 7 天全家抽卡 | 家族福池 +50 | 团队性激励 |
| 邀请一位家人入「家」 | +30 | 裂变激励 |

**规则**：
- 福值分两层：**个人福值**（攒福禄，兑换个人头像挂件）+ **家族福池**（全家人福值自动汇入，决定家族榜排名）
- 福值只涨不跌，**永不惩罚**（中老年用户被扣分 = 卸载）
- 榜单以"家族"为单位，家族名 = "王家庄""刘家大院"（默认生成，可改）

### 3.2 每日福卡（核心仪式）

**流程**：

```
推送「今天的福卡到了」(7:30)
  → 打开小程序，中央一支金色签筒
  → 摇一摇手机（或点按钮）→ 签筒晃动 → 一道金光
  → 翻出福卡：「平安卡 · 今日宜多喝水，家人无恙」
  → 卡片底部一行小字：「转发到家人群，为全家激活」
  → 转发 → 卡片点亮金边 → "全家福卡已生效 +10 福值"
```

**福卡设计规范**：
- 每天 1 张，全家族抽到的是**同一张**（"咱们家今天的福卡"——归属感）
- 卡面：国风插画（锦鲤/寿桃/福字/平安锁），日期 + 家族名，**必须有"王家庄 全家"字样**（专属感）
- 福卡等级：平安卡（70%）→ 如意卡（25%）→ 鸿福卡（5%）——稀有度刺激晒卡
- 等级只影响卡面华丽程度和附赠微任务数量（如意卡 2 个任务），**不影响福值倍率**（避免"抽不到好卡"的挫败）
- 微任务从生活化任务库随机：多喝水 / 散步 20 分钟 / 早睡 / 给家人打个电话 / 泡脚
- **合规红线（见 §7）**：福卡文案只做"祝福"，绝不做"预测"。禁用：运势、吉凶、求签、算命、改运、挡灾。卡面永远是正面祝福语。

### 3.3 「添福」互动（替代原「点个赞」，情感浓度升级）

- 团主页每位家人头像旁有「添福」按钮（金色小葫芦图标）
- 点击 → 对方收到订阅消息：「儿子给您添福啦！全家福值 +8」
- 每天给每位家人限 1 次（稀缺才珍贵，泛滥就变成点赞）
- **「给家人打个电话」本身是微任务**：福值体系鼓励真实联系，这是产品的道德底色

### 3.4 「催福」提醒（替代原「催一下」，语气重设计）

- 家人今日未抽卡 → 团主页显示"还没接福"
- 「催福」按钮 → 对方收到：「王阿姨请您接今日福卡，全家人就等您啦！」
- 文案库核心原则：**全家在等您**（归属感召唤），不是"您偷懒了"（批评）
- 每人每天对同一位家人限 3 次

### 3.5 家族福值榜（攀比引擎，传播主战场）

**三层榜**：

| 榜 | 范围 | 内容 |
|---|---|---|
| 家内榜 | 本家成员 | 本周谁为家里攒福最多（家庭内部攀比，安全） |
| 好友家族榜 | 微信好友的家族 | "老王家 890 · 老李家 720"（家族对家族） |
| 同城家族榜（V1.1） | 同城/同县 | 「岳阳县福值榜第 3 名」——地域认同感爆炸 |

**排名文案示例**：
- 落后时："就差 120 福值追上老李家了，今天全家抽卡就能反超！"
- 领先时："稳住！老李家本周奋起直追中"（制造假想敌）

**门牌体系（核心炫耀物）**：

| 家族累计福值 | 解锁 |
|---|---|
| 500 | 青铜门牌「勤俭之家」 |
| 2000 | 白银门牌「和睦之家」 |
| 5000 | 金字门牌「满门福气」 |
| 20000 | 玉匾「福泽满堂」 |

- 门牌 = 家族群头衔的视觉化，设计成**可以直接设为群头像**的正方形图
- 每次升级门牌 → 全家收到通知 → 门牌分享卡自带小程序码 → **榜外家族扫码进入**（裂变闭环）

### 3.6 节气/节日大事件（传播爆点日历）

| 时点 | 玩法 |
|---|---|
| 每逢节气 | 限定福卡（立冬"添衣卡"、冬至"团圆卡"），卡面更华丽 |
| 春节 | 「全家集五福」：福/禄/寿/喜/财五张卡，**全家分工集齐才有大奖门牌**（强拉新） |
| 重阳 | 「敬老福」：子女给父母添福 9 次，解锁专属"长寿面"动效卡片 |
| 家人生日 | 当日全员福卡变为「寿星专属版」，家人添福翻倍 |

## 4. 关键用户流程

### 4.1 新用户首日（黄金 60 秒）

```
家人群点开福卡分享链接
  → 微信授权（头像昵称，一个弹窗）
  → 直接看到「王家庄今天的福卡」+ 大按钮「我也要抽」
  → 摇一摇 → 翻卡 → 金光 → "您已为王家庄接福 +5"
  → 底部浮现「转发激活，为全家 +10」
  → 转发回家人群（用户已经在群里，成本为零）
```

**验收标准**：新用户从点开链接到完成第一次转发，≤ 4 次点击，零键盘输入。

### 4.2 裂变循环

```
王阿姨每日发福卡到家人群
  → 儿子小刘看到 → 进小程序 → 建立自己小家的关联
  → 王阿姨的门牌升级发到广场舞群
  → 老陈看到"满门福气"不服 → 拉自己全家建榜
  → 老陈的子女被拉入 → 循环
```

两条裂变链：
1. **福卡链**（每日高频，家族内纵向传播）
2. **门牌链**（低频高势能，家族间横向传播，决定增长天花板）

### 4.3 每日触点（严格频控）

| 时间 | 触点 | 频控 |
|---|---|---|
| 7:30 | 「今天的福卡到了」 | 每日 1 次 |
| 任意 | 「家人给您添福啦」 | 实时，但聚合推送 |
| 20:30 | 「全家人就差您没接福啦」 | 仅当日未抽卡用户 |

每人每日订阅消息 ≤ 4 条（合规硬约束）。

## 5. 页面结构（MVP 共 4 页 + TabBar 2 个）

```
TabBar（2 个）
├── 福卡页（首页）: 签筒摇卡 → 今日福卡 → 转发激活 → 微任务打卡
└── 我的家: 家族福值池、成员状态墙、添福/催福、门牌展示

独立页
├── 建家流程页（家族名默认生成 → 邀请卡片）
├── 家族榜页（家内榜 + 好友家族榜）
└── 门牌/福卡分享预览页
```

### 5.1 适老化设计规范（强制，沿用并强化）

| 项 | 规范 |
|---|---|
| 正文字号 | ≥ 17pt，核心信息 ≥ 22pt |
| 主按钮 | 高度 ≥ 88rpx，一屏 1 个主按钮 |
| 配色 | 高对比度；金色为主色调，喜庆但避免红绿并置 |
| 摇一摇 | 必须提供等效大按钮「点一下抽福卡」（不强制摇手机） |
| 交互深度 | 任何功能 ≤ 3 次点击 |
| 文案 | 口语化、用"您"、零英文术语 |
| 动画 | 抽卡金光动画 ≤ 2.5 秒，可跳过设置（低端机） |

## 7. 风险与合规（本产品最高优先级）

| 风险 | 等级 | 对策 |
|---|---|---|
| **微信审核：封建迷信类目** | 🔴 极高 | 全产品文案**只祝福不预测**：禁用"运势/吉凶/求签/算命/改运/挡灾/化解"，统一用"福卡/祝福/平安/福气"；福卡等级不与任何"命理"挂钩，仅是稀有度玩法；提交审核时以"民俗祝福、家庭互动"定位申报；**上线前做一次全文案迷信词扫描** |
| 诱导分享 | 🔴 高 | 微信禁止"分享后才能解锁功能"。设计口径：福卡**不转发也生效**，转发只是"额外 +10 福值"奖励——奖励分享而非强制分享，规避审核红线（对内文案可强化"为全家激活"的情感暗示，但产品逻辑上必须可完成） |
| 订阅消息骚扰 | 🔴 高 | 每人每日 ≤ 4 条；催福限 3 次/人/天 |
| 医疗暗示 | 🟡 中 | 微任务只用生活化表述（喝水/散步/泡脚），禁用任何疗效词 |
| 道德边界 | 🟡 中 | 内部原则：可以放大"惦记家人"的情感，绝不制造"不转发家人会有事"的恐惧暗示；福卡文案库建立负面清单 |
| 隐私 | 🟡 中 | 家族榜仅好友可见；提供"隐身榜外"开关 |

> ⚠️ 诱导分享条款需要特别注意：微信明确打击"分享后才能继续操作"。因此 3.2 节"转发才激活"必须实现为**软引导**（不转发福卡也计入家族福池，转发只是加成），文案说"为全家激活"是情感包装，功能上无强制。这是合规与增长设计的分界线。

## 8. 版本规划

| 版本 | 范围 | 目标 |
|---|---|---|
| **MVP (v1.0)** | 建家/邀请、每日福卡（摇卡/翻卡/转发）、5 项微任务、添福、催福、家内榜+好友家族榜、青铜/白银门牌 | 验证「福卡分享率 ≥ 60%」，跑通福卡链+门牌链双裂变 |
| v1.1 | 节气限定卡、同城家族榜、连续抽卡奖励、订阅消息优化 | 拉开传播势能 |
| v1.2 | 春节集五福、生日专属卡、福卡模板个人化 | 爆点日历事件化 |
| v2.0 | **老照片修复付费**（9.9 元全家福修复，福卡情感的自然延伸）、高级门牌模板 | 商业化验证 |

**MVP 明确不做**：支付、老照片修复、自定义福卡、私信、同城榜、提现。
